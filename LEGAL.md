# Legal/IP Protection Playbook

This repository is proprietary. The `LICENSE` file provides baseline legal
terms, but practical protection requires operational controls.

## 1. Required controls before sharing source
1. Execute a signed NDA with the recipient.
2. Execute a signed evaluation/commercial agreement referencing this repo.
3. Provide access only to named individuals on a need-to-know basis.
4. Use private repos and least-privilege access; no public mirrors.
5. Log who received access and when access was removed.

## 2. Internal controls
1. Ensure all employees/contractors have signed IP assignment + confidentiality
   agreements.
2. Revoke credentials immediately at offboarding.
3. Restrict copying/export of source archives.
4. Keep proprietary headers intact in all files.

## 3. Contributions
1. Do not accept external contributions without a signed CLA or equivalent
   assignment/license agreement.
2. Keep records of signed agreements by contributor identity and date.

## 4. Enforcement hygiene
1. Preserve commit history and access logs.
2. Register copyrights where applicable.
3. Evaluate patent filings for core inventions before broad disclosure.

## 5. Important note
This document is operational guidance, not legal advice. Engage qualified
counsel for jurisdiction-specific enforceability and deal terms.
